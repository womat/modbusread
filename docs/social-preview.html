modbusread

Read registers from any Modbus device – and see the raw words.

TCP · RTU / RS-485 · read-only · single binary 
$ modbusread 192.168.1.50 42082 uint16
addr     raw                  value
42082    0x0064               100

$ modbusread 192.168.1.50 40574 float32 \
      --word-order low
addr     raw                  value
40574    0x8000 0x45A3        5232

$ modbusread /dev/ttyUSB0 40069 uint16 \
      --baud 9600 --parity even --unit 3
addr     raw                  value
40069    0x00E6               230

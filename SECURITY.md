# Security

`modbusread` only reads – it has no write path to a Modbus device. Reports of security
issues are taken seriously all the same.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub instead:
**Security → Report a vulnerability** ([direct link](https://github.com/womat/modbusread/security/advisories/new)).

Helpful details:

- the affected version (`modbusread --version`)
- steps to reproduce
- what an attacker could achieve with it

You will usually get an answer within a week. This is a spare-time project, so no fixed response time can be
promised.

## Supported versions

Security fixes are made for the latest release only.
